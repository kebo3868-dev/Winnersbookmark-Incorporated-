# Winners Bookmark CRM — Prospect Tracker Guide

**File:** `prospect-tracker.csv` — open in Google Sheets or Excel. This is your single source of truth for every lead.

## How to use it
1. One row = one business. Never delete a row; change its **Outreach Status** instead.
2. Fill **Priority (1-10)** the moment you research a business so you always know who to contact first.
3. After any approved outreach, set **Outreach Date** and a **Follow-Up Date** 3–4 days later.
4. When someone replies, mark **Reply? = Yes** and write the exact **Next Step**.

## Column definitions
| Column | What goes here |
|---|---|
| Business Name | Legal/brand name |
| Website | Full URL |
| Phone | Public number |
| Email | Owner/manager email if found (never guess-send) |
| Instagram | @handle |
| Location | City, FL |
| Google Rating | e.g. 4.3 |
| Reviews Count | Number of Google reviews |
| Website Problem | The single most visible friction point |
| AI Opportunity | The AI Front Desk feature that fixes it |
| Best Outreach Angle | The one-line hook for your message |
| Priority (1-10) | 10 = obvious pain + reachable owner |
| Outreach Status | Not Contacted / Drafted / Sent / Replied / Call Booked / Audit Sent / Proposal Sent / Won / Lost / Nurture |
| Outreach Date | When the first message went out |
| Follow-Up Date | Next scheduled touch |
| Reply? | Yes / No |
| Next Step | The literal next action |
| Notes | Owner name, context, objections |

## Status flow
`Not Contacted → Drafted → Sent → Replied → Call Booked → Audit Sent → Proposal Sent → Won / Lost / Nurture`

## Daily rule
Every day, sort by **Priority** descending, filter **Outreach Status = Not Contacted**, and work the top of the list. Then check **Follow-Up Date = today** and send approved follow-ups.
